## 要产出的交付物

1. **设计系统基底**：间距 / 圆角 / 阴影 / 字体阶梯 / 动效 token 的视觉规范（喂架构 P6 动画 token + 通用组件）
2. **每个朝代「世界」的视觉方向 + design token 真值**：明 / 唐（+规划宋…）的配色·字体·纹样·氛围·留白·布局气质，**具体到能填进架构 P2 主题管线的 token 值**（现 spec 里 Tang 是占位「绢色/金色」，需定稿）
3. **招牌场景详细设计**：明=票拟批红「制衡天平」、唐=三省封驳公文流转、宋=清明上河图门户——长什么样 + 动效编排（喂 P7 关系图谱 / P8 穿越转场）
4. **关键界面设计**：首页/世界入口、分区展厅、机构卡片(L0)、详情抽屉(L1)、深读遮罩(L2)、关系图谱全景、穿越过场
5. **微交互 / 打磨规范**：套用 `make-interfaces-feel-better` 清单

## 必须遵守的约束（来自标准，不可违背）

- 温度 A：编辑级克制 + 关键电影感；Motion + GSAP，**不引入 pixijs/remotion**
- 引导式叙事为骨 + 休息点可选交互
- B+：每朝代迥然不同的**沉浸世界**，共享交互语法；以**穿越转场**连接
- 关系图谱：**策展式**、墨色按类型编码、聚焦高亮；**绝不裸力导向 / 不可拖拽**
- 内容分层 L0/L1/L2；外链「延伸阅读」克制靠后、沉浸优先
- 设备：桌面专属沉浸 + 移动端保底可读；reduced-motion 平台级三态
