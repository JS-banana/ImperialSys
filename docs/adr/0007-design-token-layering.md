# 设计令牌分层：结构令牌「平台共享」+ 表达令牌「朝代独占」+ 站位「在共享阶梯上选档」

界面设计阶段开篇即需定下：每个「朝代世界」到底自定义多少？这把 [ADR-0003](./0003-per-dynasty-differentiation-boundary.md) 的「能力下沉平台、世界上浮朝代」从架构边界落到**设计令牌的具体分桶**，直接决定架构 P2 主题管线里 `theme.ts` 携带什么、不携带什么。

决策：**令牌按「结构 / 表达」两分，外加「站位」逃生口。**

- **结构令牌（平台共享，单一真源）**：间距阶梯、圆角阶梯、阴影分级（elevation）、字阶比例（type-scale ratio）、动效时长/缓动/错峰（duration/easing/stagger）、组件解剖与交互模式（卡片/抽屉/遮罩/图谱的骨架与「怎么点、怎么深潜」）。**这就是「看不见的交互语法」——一致性在此，用户跨朝代不重学。**
- **表达令牌（朝代独占）**：配色（语义色板）、字体家族、纹样/质感、背景氛围、招牌构图。**这就是「看得见的世界」——迥然不同在此。**
- **站位（朝代在共享阶梯上选档，非另起阶梯）**：朝代可在结构阶梯内选「站位」以拉开气质——密度（疏／密，选基础间距档）、阴影暖度（墨色/暖褐 tint，仍用共享 elevation 级数）、描边墨色（line 用本朝 ink，仍用共享粗细/圆角）。**选的是「档位与染色」，不是「另造一套阶梯」**——既拉开气质，又不破坏语法。

## Considered Options

- **全部共享，只换 color+font**：否决——最稳最省，但「迥然不同的沉浸世界」(ADR-0003 B+) 全靠配色字体撑，气质差异不足，沉浸感打折。
- **朝代全权自定义（连间距/圆角/动效都各自从零）**：否决——给出相同视觉效果却让交互语法漂移（违背 ADR-0003「不要让用户思考」）、维护爆炸；ADR-0003 已否决同型的方案 C。
- **结构共享 · 表达独占 + 站位**：✅ 选中。结构一致守语法、表达独占造世界、站位补足「同结构也能拉开气质」的张力。

## Consequences

- **架构 P2 主题管线的 `theme.ts` 只携带「表达令牌 + 站位选择」**（color/font/纹样/氛围/招牌 + density 档、shadow tint、line ink 的引用）；结构令牌（间距/圆角/阴影级数/字阶比例/动效）住平台、不进每朝代 `theme.ts`。这收窄了 P2 的 `DynastyTheme` schema 形状。
- **结构令牌真值**（间距/圆角/阴影/字阶/动效）由本设计阶段产出，喂架构 P6 动画基建与通用组件；写入设计系统 spec，受 Zod 必填约束（接 P1/P2 校验链）。
- 「迥然不同」的验收（ADR-0003 验收点 4）由**表达令牌差异 + 站位差异**共同保证，而非靠各自重写结构。
- 朝代异形视觉（超出表达令牌能表达者，如招牌场景的特殊构图）走朝代自有 CSS/组件逃生口（与架构方案「方案 C + 朝代自有 CSS 逃生口」一致）。
