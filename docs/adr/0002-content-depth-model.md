# 内容深度模型：分层深读（L0/L1/L2）+ 内容原子互链

现状的内容模型是「扁平一层百科」——每个机构只有 4 个职能图标 + 一段结构说明 + 几个下属机构名词，事件/人物作为机构的附属数据，点不进、串不起。后果：宏观体验尚可，但用户想深究某一点时频繁「撞空」，对受众中的深究人群（历史爱好者）尤其不足。在 2026-06-28 的访谈中，确认「微观有料」是与「宏观丝滑」并列的体验支柱，并选定内容模型为：

**(1) 分层深读**——每个机构支持渐进式深度：
- **L0 卡片**：一句话定位 + 类别 + 核心职能（速览）
- **L1 详情抽屉**（现有 4 Tab）：职能与结构 / 关系网络 / 历史演变 / 代表人物
- **L2 深读长文**：制度沿革、运作机制、为何如此设计、关键事件、史料引文、延伸阅读

**(2) 内容原子互链**——事件、人物、概念（如「制衡机制」「票拟批红」）从「机构的附属字段」升级为**一等内容原子**，各有可单独查看的承载，可从任意处互链跳转。硬指标：**深究任何一个点都不撞空。**

数据策略：结构化原子（受 Zod 校验、保证引用完整性）+ 富文本长文（MDX 或 markdown 字段）。利用「历史确定、数据易得」的前提，难点落在可维护的内容架构、而非取材。

## Considered Options

- **加厚现有扁平结构**（只填满 4-Tab、不加层级）：否决——深究仍终止于机构层，事件/人物仍点不进，爱好者天花板依旧低。
- **知识库/百科式自由漫游**（无限互链自由漫游）：否决——工量大、易迷路、喧宾夺主，与已选定的「引导式博物馆动线」相冲突。
- **分层深读 + 内容原子互链**：✅ 选中。与「引导叙事 + 休息点深潜」咬合；学生/教师用 L0-L1、爱好者深潜 L2 并顺原子互链下去；契合「渐进式展示」。

## Consequences

- 数据模型需从扁平 JSON 升级：事件/人物/概念成为一等实体，需要各自的 schema 与 id 体系，并支持跨原子引用。
- 这把「Zod 校验该不该救活」从可选变成**必需**——内容原子互链的引用完整性必须被校验，否则深读链接会断。直接约束后续架构决策。
- L2 深读需要富文本承载方案（MDX / markdown）——新增技术选型，待架构阶段定。
- 「微观有料」成为验收「完美体验」的硬标准之一：抽查若干机构，深究链路不得撞空。
