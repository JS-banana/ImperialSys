# 关系可视化：双层「策展式」图谱（绝不裸力导向），关系图谱作为平台能力

「理解政治制度＝理解关系/制衡」是项目灵魂。现状：数据层已是高质量有向图（22 条关系、5 种类型、带描述），但渲染层全是手工硬编码——`MiniStructureMap` 手写坐标、且把连线另起一份与 `relations.json` 脱钩（漂移风险、只画 15/22 条、不区分类型，全灰线）；`RelationDiagram` 是 4 张 100% 手绘 SVG。项目最早用 React Flow（节点连线画布），已被 v2 拆除（编辑器范式、滚轮被劫持、不适合阅读）。

用户要求「偏可视化的图谱/连线，但必须美观、不粗糙」。决策：

**绝不使用裸力导向 / 自动布局图谱（force-directed）**——它天生「毛球化(hairball)」、丑，正是「粗糙」的来源，也是 React Flow 被拆的原因。美来自四件事：**策展式布局**（位置经设计、表意：纵向＝权力自上而下、对称＝制衡对峙、围合＝会审环路）、**墨笔连线 + 按关系类型着色编码**（制衡＝朱红双向虚线、统辖＝实线、监察＝点线）、**聚焦渐进式揭示**（hover/点某机构 → 其关系点亮、余者隐退，绝不一次糊全网）、**会解释的动效**（连线自绘 pathLength、权力流光、制衡用天平/张力）。

形态为**双层，皆策展**：
- **全景策展图谱**：每个朝代一张数据驱动、布局策展、可聚焦高亮（**不可拖拽编辑**）的权力全景图，作为该朝代世界的招牌展品。
- **情境电影编排**：叙事中就地把关键关系电影化展开（GSAP 滚动驱动），系统化替代 4 张手绘。
- 加详情抽屉关系 Tab（单机构 incoming/outgoing）。

按 B+（[ADR-0003](./0003-per-dynasty-differentiation-boundary.md)），**关系图谱机制是平台能力**（数据驱动 + 策展布局支持 + 类型墨色编码 + 聚焦高亮 + 自绘/流光动效），**每个朝代策展自己的布局与墨色**。

## Consequences

- 新建平台「关系图谱原语」；关系升级为内容原子（与 [ADR-0002](./0002-content-depth-model.md) 一致），布局可由 dagre/elk 类工具辅助生成后再人工微调，渲染用自有 SVG + Motion/GSAP。
- **不引入 React Flow / cytoscape / sigma 等重图谱库**——守住静态导出、美学控制权与温度 A；也阻止后人「再装个图谱库」把已删的编辑器范式带回来。
- `MiniStructureMap` 的「连线与 `relations.json` 脱钩」需消除——图谱一律由校验过的关系数据驱动（接 ADR-0002 的 Zod 引用完整性）。
- 保持「阅读/观展」范式：不可拖拽编辑、不劫持滚轮。
