# ImperialSys | 大明政治制度可视化系统

> “以明朝为起点，先把制度骨架讲清楚，再逐步扩展到其他朝代。”

ImperialSys 是一个专注于中国古代政治制度演变的交互式可视化项目。它通过现代的前端技术，将枯燥的历史文献转化为直观、生动的权力架构图谱，帮助用户深入理解大明王朝权力中枢的运转逻辑。

## 🌟 核心特性

- **叙事驱动的制度骨架**：项目按“皇权独尊”、“票拟与批红”、“六部执行”等六大核心章节展开，逻辑严密地勾勒出大明中枢的权力版图。
- **交互式权力图谱**：利用动态关系连带（Relation Band）与架构图解（Diagrams），直观展示内阁、司礼监、都察院等机构间的制衡与协作。
- **深度细节透视**：点击具体机构，即可进入详情抽屉，查阅核心职能、代表人物及相关历史事件。
- **极致的交互体验**：基于 Framer Motion 实现丝滑的滚动监听（ScrollSpy）与动效，让历史的学习过程更具沉淀感。

## 🛠 技术栈

- **框架**：[Next.js 16](https://nextjs.org/) (App Router) + [React 19](https://react.dev/)
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) + [Base UI](https://base-ui.com/)
- **动画**：[Framer Motion](https://www.framer.com/motion/)
- **语言**：TypeScript
- **部署**：Vercel

## 🚀 快速开始

1. **克隆仓库**
   ```bash
   git clone <your-repo-url>
   cd ImperialSys
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发环境**
   ```bash
   npm run dev
   ```

4. **构建生产版本**
   ```bash
   npm run build
   ```
